# WoomanCalendar

[English](README.md) · [Русский](README.ru.md) · **Українська** · [Deutsch](README.de.md) · [Español](README.es.md)

Особистий календар місячних і циклу для Android, працює офлайн. Позначте перший день місячних — календар спрогнозує наступні місячні, фертильне вікно та овуляцію. Без акаунта, реклами, аналітики й серверів: дані зберігаються на телефоні та дублюються на **ваш власний Google Drive**.

> Прогноз орієнтовний, це не медична рекомендація і не метод контрацепції.

## Можливості

- Календар по місяцях: місячні, прогноз, фертильне вікно, овуляція
- Позначка початку/кінця місячних одним дотиком; інтенсивність, симптоми та нотатки по днях
- Прогноз за останніми 6 циклами (свіжі цикли важать більше)
- Дані зберігаються при оновленні застосунку (та сама назва пакета й той самий ключ підпису)
- Автоматична JSON-копія у файл на вашому Google Drive — без реєстрації в Google Cloud і без входу в акаунт у застосунку
- Мови: English, Русский, Українська, Deutsch, Español (за мовою системи; вибір мови застосунку в Android 13+)

## Встановлення

1. На телефоні відкрийте [останній реліз](https://github.com/navaikashalot-ops/WoomanCalendar/releases/latest) і завантажте `WoomanCalendar-<N>.apk`.
2. Відкрийте файл. Якщо Android попросить — дозвольте встановлення з цього джерела (браузер або файловий менеджер): *Налаштування → Застосунки → Особливий доступ → Встановлення невідомих застосунків*.
3. Натисніть **Встановити** й відкрийте застосунок.
4. **Оновлення:** встановлюйте новий APK поверх старого. **Не видаляйте застосунок** — під час видалення локальні дані стираються.

Потрібен Android 8.0 (API 26) або новіший.

## Копія в Google Drive (один раз)

1. У застосунку: **Налаштування** → **Створити файл копії** → у системному вікні оберіть *Google Drive* → збережіть `cycle-backup.json`.
2. Далі файл оновлюється автоматично після кожної зміни.
3. Новий телефон або перевстановлення: **Налаштування → Відновити з файлу** → оберіть `cycle-backup.json` на Drive.

Штатний Auto Backup Android також зберігає копію, але для APK не з Google Play його відновлення не гарантоване — орієнтуйтеся на файл на Drive.

## Зібрати самостійно (GitHub Actions)

1. Зробіть fork репозиторію.
2. Один раз створіть ключ підпису: `bash scripts/make-keystore.sh` (потрібен JDK). **Збережіть `mycycle.jks` і пароль** — з іншим ключем оновлення не встане поверх старого, а локальні дані зникнуть.
3. Додайте секрети репозиторію `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_PASSWORD`, `KEY_ALIAS` (скрипт виведе команди).
4. Зробіть push у `main` або запустіть workflow **Build APK**. APK з’явиться в розділі *Releases*.

Стек: Kotlin, Jetpack Compose, Room, kotlinx.serialization.

## Конфіденційність

Немає мережевих дозволів і аналітики. Дані лежать у приватному сховищі застосунку та у файлі копії, який обираєте ви.
