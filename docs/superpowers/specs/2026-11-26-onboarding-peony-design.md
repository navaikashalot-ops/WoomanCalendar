# Знакомство, профиль и дизайн «Пион»

## Зачем

Приложение сейчас выглядит как стандартный Material-шаблон, в календаре у дня с записью видна только точка, профиля нет. Владелица хочет, чтобы приложение было нежным и женственным, встречало по имени и с аватаркой, а в календаре сразу было видно, что отмечено в каждый день. Украинский язык из приложения убирается.

## Цели

1. Убрать украинскую локализацию.
2. Экран первого запуска из двух шагов:
   - шаг 1: выбор аватарки из 8 нарисованных и ввод имени;
   - шаг 2: дата начала последних месячных, обычная длина цикла и длительность месячных; можно пропустить кнопкой «Не помню».
3. Профиль (имя и аватарка) хранится в базе и в резервной копии на Drive; его можно поменять в настройках.
4. Дизайн «Пион» на всех экранах: календарь, диалог дня, настройки, онбординг.
5. Своя векторная графика: 14 иконок состояний, 8 аватарок, декоративный пион.
6. В клетке календаря показываются иконки отмеченных за день состояний.
7. Список состояний расширяется: к текущим пяти добавляются настроение (хорошее, грусть, раздражение), секс, таблетка, тяга к сладкому.

## Не цели

- Фото из галереи в качестве аватарки.
- Новые функции прогноза, напоминания, уведомления.
- Тёмная тема (можно позже; сейчас только светлая).

## Анти-цели (провал, даже если работает)

- Обновление стирает или ломает данные уже установленной версии: схема меняется только через явную миграцию Room.
- Старая резервная копия перестаёт восстанавливаться.
- Пользователь, у которого уже есть данные, после обновления вынужден заново проходить онбординг с вводом цикла.

## Ограничения

- Kotlin, Jetpack Compose (BOM 2024.06), Material3, Room 2.6.1, kotlinx.serialization; minSdk 26.
- Нет сетевых разрешений, всё офлайн.
- Сборка идёт в GitHub Actions; локально JDK есть, Android SDK нет.
- Языки: en (по умолчанию), ru, de, es. Все новые строки переводятся на все четыре.

## Подходы, которые рассматривали

- **А. Эмодзи** для иконок и аватарок. Просто, но выглядит по-разному на разных телефонах и не даёт единого стиля.
- **Б. Material Icons.** Одноцветные и строгие, женственно не выходит. Отброшен.
- **В. Свои векторные рисунки (выбран владелицей).** Единый стиль, больше работы. Рисунки уже согласованы в макете: `.superpowers/brainstorm/*/content/style-v1.html`.

## Что решено

### Палитра «Пион»

| Роль | Цвет |
|---|---|
| Фон | `#FDF2F5` |
| Карточки | `#FFFFFF` |
| Текст | `#5B2A44` |
| Вторичный текст | `#A1748B` |
| Акцент (кнопки, сегодня, прогресс) | `#E8668C` |
| Месячные (клетка) | `#FBD3DE` |
| Прогноз месячных | `#FDE7EE` + пунктирная акцентная рамка |
| Фертильное окно | `#E3F4EA` |
| Овуляция | `#ECE4FB` |

Шрифт: Nunito (округлый), подключается через ресурсы `res/font` (файлы OFL). Карточки со скруглением 24dp, кнопки 18dp. Клетка календаря в форме лепестка: углы 16/16/16/6dp.

### Главный экран

Сверху: аватарка, приветствие по времени суток («Доброе утро/день/вечер») и имя; в правом верхнем углу декоративный пион. Под ним карточка с кольцом «день цикла» и строками про следующие месячные и текущую фазу. Затем календарь месяца и две кнопки: «Начались сегодня» (или «Закончились сегодня») и «Записать день».

### Иконки в календаре

В клетке под числом до двух иконок. Порядок приоритета: месячные (если отмечена интенсивность) → настроение → симптомы → секс → таблетка → сладкое → заметка. Овуляция показывается иконкой только если в этот день нет записей. Если иконок больше двух, видны первые две.

### Профиль и данные

- Новая таблица/поля профиля: имя (строка, может быть пустой), id аватарки (строка-ключ, например `bun`), флаг «онбординг пройден».
- Миграция Room 1 → 2 добавляет это без потери данных.
- Существующие пользователи (есть хотя бы один цикл) после обновления видят только шаг 1 онбординга (имя и аватарка); шаг 2 им не показывается.
- `Snapshot` получает поле `profile` со значением по умолчанию, `schemaVersion` = 2; копии версии 1 продолжают восстанавливаться.
- Новые состояния хранятся в существующем поле `symptoms` (через `|`) новыми ключами; настроение — тоже ключ в этом поле, одно значение из трёх.

### Онбординг, шаг 2

Если указана дата, создаётся первый цикл с этой даты, а длины записываются в настройки. «Не помню» — пропустить, настройки остаются по умолчанию (28/5).

### Уточнения (решения Claude после проверки документа)

- **Кто «существующий пользователь».** Это тот, у кого в базе есть хотя бы один цикл или хотя бы одна запись дня. Проверка делается при запуске: если флаг онбординга не выставлен, а данные есть, показывается только шаг 1.
- **Восстановление копии версии 1.** В копии v1 нет профиля, поэтому текущий профиль из базы сохраняется, а не затирается. Онбординг считается пройденным, если в восстановленных данных есть циклы или записи.
- **Ключи состояний в `symptoms`.** Пять старых ключей не меняются. Старый `mood` («плохое настроение») теперь показывается как «Грусть». Новые ключи: `mood_good`, `mood_angry`, `sex`, `pill`, `sweet`. Из трёх настроений (`mood_good`, `mood`, `mood_angry`) можно выбрать только одно. Если в записи их оказалось несколько, показывается первое по этому порядку.
- **Иконок 14:** месячные, фертильное окно, овуляция, 5 симптомов (боль, голова, вздутие, усталость, грусть = `mood`), хорошее настроение, раздражение, секс, таблетка, сладкое, заметка.
- **Рисунки.** Макет копируется в репозиторий: `docs/superpowers/specs/assets/peony-mockup.html`. Аватарки: `bun`, `long`, `curly`, `cat`, `bunny`, `peony`, `butterfly`, `moon`.
- **Шрифт Nunito.** Файлы TTF (OFL) кладутся в `app/src/main/res/font` и коммитятся. CI ничего не скачивает.
- **Онбординг, шаг 2.** Если дата указана, длины берутся из степперов, по умолчанию 28 и 5. Пустых значений нет.
- **Украинский.** `values-uk` и `uk` в `locales_config` удаляются. У тех, у кого выбран украинский, интерфейс откатится на английский.
- Условие показа «Закончились сегодня» не меняется.

## Остаётся на усмотрение исполнителя

- Как разбить `MainScreen.kt` на файлы.
- Перерисовка SVG из макета в Android VectorDrawable (по возможности близко к макету).
- Точные отступы, размеры шрифтов, анимации (сдержанно).
- Выбор даты в онбординге: стандартный DatePicker из Material3.
