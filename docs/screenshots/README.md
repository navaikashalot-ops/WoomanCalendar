# Screenshots

Put real screenshots of the running app here, named:

- `calendar.png` — main calendar screen
- `day.png` — day dialog (flow, symptoms, note)
- `settings.png` — settings and backup

How to take them: install the APK, then either use the phone's screenshot buttons and copy the files here,
or run `adb exec-out screencap -p > docs/screenshots/calendar.png` with the phone connected.

Then uncomment the `<p>...</p>` block in the "Screenshots" section of each `README*.md` and remove the "coming soon" line.
Do not publish screenshots that contain your real health data.
