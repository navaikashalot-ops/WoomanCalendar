# WoomanCalendar

[English](README.md) · **Русский** · [Українська](README.uk.md) · [Deutsch](README.de.md) · [Español](README.es.md)

Личный календарь месячных и цикла для Android, работает офлайн. Отметьте первый день месячных — календарь спрогнозирует следующие месячные, фертильное окно и овуляцию. Без аккаунта, рекламы, аналитики и серверов: данные хранятся на телефоне и дублируются на **ваш собственный Google Drive**.

> Прогноз ориентировочный, это не медицинская рекомендация и не метод контрацепции.

## Возможности

- Календарь по месяцам: месячные, прогноз, фертильное окно, овуляция
- Отметка начала/конца месячных в одно касание; интенсивность, симптомы и заметки по дням
- Прогноз по последним 6 циклам (свежие циклы важнее)
- Данные сохраняются при обновлении приложения (то же имя пакета и тот же ключ подписи)
- Автоматическая JSON-копия в файл на вашем Google Drive — без регистрации в Google Cloud и без входа в аккаунт внутри приложения
- Языки: English, Русский, Українська, Deutsch, Español (по языку системы; выбор языка приложения в Android 13+)

## Установка

1. На телефоне откройте [последний релиз](https://github.com/navaikashalot-ops/WoomanCalendar/releases/latest) и скачайте `WoomanCalendar-<N>.apk`.
2. Откройте файл. Если Android попросит — разрешите установку из этого источника (браузер или файловый менеджер): *Настройки → Приложения → Особый доступ → Установка неизвестных приложений*.
3. Нажмите **Установить** и откройте приложение.
4. **Обновление:** ставьте новый APK поверх старого. **Не удаляйте приложение** — при удалении локальные данные стираются.

Нужен Android 8.0 (API 26) или новее.

## Копия в Google Drive (один раз)

1. В приложении: **Настройки** → **Создать файл копии** → в системном окне выберите *Google Drive* → сохраните `cycle-backup.json`.
2. Дальше файл обновляется автоматически после каждого изменения.
3. Новый телефон или переустановка: **Настройки → Восстановить из файла** → выберите `cycle-backup.json` на Drive.

Штатный Auto Backup Android тоже хранит копию, но для APK не из Google Play его восстановление не гарантировано — ориентируйтесь на файл на Drive.

## Собрать самому (GitHub Actions)

1. Сделайте fork репозитория.
2. Один раз создайте ключ подписи: `bash scripts/make-keystore.sh` (нужен JDK). **Сохраните `mycycle.jks` и пароль** — с другим ключом обновление не встанет поверх старого и локальные данные пропадут.
3. Добавьте секреты репозитория `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_PASSWORD`, `KEY_ALIAS` (скрипт выведет команды).
4. Сделайте push в `main` или запустите workflow **Build APK**. APK появится в разделе *Releases*.

Стек: Kotlin, Jetpack Compose, Room, kotlinx.serialization.

## Конфиденциальность

Нет сетевых разрешений и аналитики. Данные лежат в приватном хранилище приложения и в файле копии, который выбираете вы.
